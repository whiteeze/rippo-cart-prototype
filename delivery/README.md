# RIPPO — финальный комплект сдачи

Макет согласован. Комплект для передачи заказчику и внедрения на стороне RIPPO.

## Онлайн

- Комплект: https://whiteeze.github.io/rippo-cart-prototype/
- Прототип: https://whiteeze.github.io/rippo-cart-prototype/prototype/?v=20261127f

## Состав папки

| Папка / файл | Содержание |
|---|---|
| `pdf/` | Документы 00–08 + PDF экранов макетов |
| `mockups/` | PNG ключевых экранов (desktop + mobile) |
| `figma/` | PNG для импорта в Figma + инструкция |
| `DELIVERY-LETTER.txt` | Готовый текст сообщения заказчику |

## Документы (PDF)

1. `01-ux-report.pdf` — UX-отчёт  
2. `02-questions.pdf` — вопросы  
3. `03-user-flow.pdf` — схема сценария  
4. `04-behavior.pdf` — поведение  
5. `05-fields-table.pdf` — таблица полей  
6. `06-acceptance.pdf` — сценарии приёмки  
7. `07-design-specs.pdf` — дизайн-спеки  
8. `08-agreed-rules.pdf` — согласованные правила  
9. `09-mockups-screens.pdf` — экспорт макетов (экраны)

## Figma (обязательно по ТЗ)

См. `figma/README-FIGMA.md`.

Нужно от заказчику передать:

1. Ссылку на редактируемый проект Figma (доступ **can view** — просмотр параметров и экспорт).  
2. Исходник `.fig` (File → Save local copy / Export .fig).  
3. PDF-экспорт макетов из Figma (или готовый `pdf/09-mockups-screens.pdf`).

> Без входа в аккаунт Figma агент не может создать `.fig` и публичную ссылку. После входа в Figma в браузере — напишите, продолжим импорт экранов и выдачу ссылки.
