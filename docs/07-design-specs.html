Адаптив — правила перестроения

  • Сводка заказа: desktop — sticky справа; mobile — compact bar снизу (итог + CTA), детали по «Подробнее».
  • Sticky CTA не перекрывает активное поле: при focus input bar скрывается или страница скроллит поле выше клавиатуры.
  • Автофокус только на поле промокода после клика «Есть промокод» и на первом ошибочном поле после submit.
  • Горизонтальный скролл запрещён; длинные названия товара — 2 строки + ellipsis.
