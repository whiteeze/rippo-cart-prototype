Готовые плагины CMS для адреса и ПВЗ

В прототипе встроены те же виджеты, которые ставят на CMS без изобретения своей подсказки.

1. Адрес доставки — DaData Suggestions

ЗачемГород, улица, дом, квартира, индекс; исправление опечаток; подстановка индекса для Почты РФ
Пакет@dadata/suggestions · CDN jsDelivr
Документацияdadata.ru/suggestions/usage/address
Где в формеКурьер СДЭК · Почта России · поле города для ПВЗ
Нужно от заказчикаAPI-ключ DaData (токен)
Dadata.createSuggestions(input, {
  token: API_KEY,
  type: "address",
  onSelect(suggestion) { /* city, postal_code, house, flat */ }
});

2. ПВЗ — виджет СДЭК

ЗачемКарта/список ПВЗ, выбор пункта, признак наложенного платежа
Пакет@cdek-it/widget · widget.cdek.ru
Где в формеСпособ «СДЭК — пункт выдачи» → «Выбрать ПВЗ на карте»
Нужно от заказчикаКлюч Яндекс.Карт + servicePath (PHP/прокси на CMS к API СДЭК)
В прототипе без servicePath показывается демо-список в том же UX. На CMS виджет открывается официально; в итог уходят адрес ПВЗ и доступность COD.

Порядок на внедрении

  1. Сначала способ доставки.
  2. ПВЗ → виджет СДЭК (домашний адрес не спрашиваем).
  3. Курьер / Почта → DaData на полном адресе (+ индекс для Почты).
  4. Если СДЭК вернул «в ПВЗ нет наложенного платежа» — другой ПВЗ или онлайн-оплата.
