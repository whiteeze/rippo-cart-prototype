Финальная сдача (макет согласован)

Статус: структура и прототип согласованы с заказчиком. Собираем и передаём полный комплект.

Что отдаём

  1. Документы 01–08 — HTML в docs/ и PDF в exports/final-kit/pdf/.
  2. Кликабельный прототип — GitHub Pages + исходники в prototype/.
  3. PDF макетов — exports/final-kit/pdf/09-mockups-screens.pdf (8 ключевых экранов).
  4. PNG экранов — exports/final-kit/mockups/.
  5. Figma — ссылка can view + файл .fig (см. exports/final-kit/figma/README-FIGMA.md). Без входа в аккаунт Figma ссылку и .fig создать нельзя — ассеты для импорта готовы.
  6. Текст письма — exports/final-kit/DELIVERY-LETTER.txt.

Порядок передачи

  1. Отправить ссылки на комплект и прототип.
  2. Приложить архив exports/final-kit (PDF + PNG + инструкция Figma).
  3. Создать Figma-файл → Share can view → положить .fig в архив → вставить ссылку в письмо.
  4. Напомнить: код на rippo.ru не ставим; внедрение на стороне заказчика.
Figma — осталось с вашей стороны: войти в Figma → импорт PNG из exports/final-kit/figma/ или html.to.design по URL прототипа → Share (can view) → Save .fig. Либо войдите в Figma в браузере Cursor и напишите «продолжи Figma».
