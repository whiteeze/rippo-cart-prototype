Список вопросов заказчику

Ответы получены (Google Sheet). Сводка правил: 08-agreed-rules.html. Ниже — исходные вопросы для архива.

Коммерческие правила

  1. Доставка до отделения ТК/Почты на странице «Оплата и доставка» указана как бесплатная, при этом тарифы СДЭК считаются при оформлении. Какое правило показывать в корзине и в итоге? блок: доставка / итог
  2. Когда доступна оплата при получении: только СДЭК ПВЗ, СДЭК курьер, оба? Есть ли лимит суммы? блок: оплата
  3. Какая часть суммы при COD оплачивается сейчас (доставка? комиссия? предоплата товара?), а какая — при получении? Нужны формулы и примеры. блок: оплата
  4. Размер и порядок расчёта комиссии за наложенный платёж / COD. блок: оплата
  5. Почта России: всегда 100% предоплата товара + доставки — подтверждаем? блок: оплата + доставка
  6. Промокод: совместим ли с общей скидкой сайта? с персональной скидкой ЛК? можно ли суммировать? блок: промокод
  7. Персональная скидка приоритетнее общей даже если меньше — остаётся? Показывать ли обе перечёркнутыми/неприменёнными? блок: скидки

Данные и поля

  1. Минимальный набор для гостя: имя, телефон, email — достаточно? Когда нужна фамилия (требования СДЭК/Почты)? блок: контакты
  2. Для курьера СДЭК: улица, дом, квартира, подъезд, домофон, комментарий — какие поля обязательны? блок: адрес
  3. Подставляем ли сохранённые адреса/ПВЗ для авторизованного пользователя? Сколько адресов хранится? блок: ЛК
  4. «Быстрый заказ»: какие поля собирает сейчас и что обещаем покупателю (звонок / счёт / сразу заказ)? блок: быстрый заказ

Технические зависимости (фиксируем, не чиним)

  1. Какие тексты ошибок реально возвращают СДЭК / Почта / виджет ПВЗ? Нужен список кодов → человекочитаемые сообщения. блок: доставка
  2. ТБанк: карта и СБП — отдельные методы или один виджет? Что видит пользователь при незавершённой оплате (ссылка на доплату без нового заказа)? блок: оплата
  3. Пересчёт корзины и скидок без перезагрузки — уже есть API или нужна доработка на стороне разработки заказчика? зависимость
  4. Адреса текущих URL: страница корзины, checkout, быстрый заказ, успех/fail оплаты. навигация
