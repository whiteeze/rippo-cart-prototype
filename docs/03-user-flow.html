Схема сценария покупки

От добавления товара до создания заказа и оплаты. Включает возвраты и ошибки.

основной путь ошибка / альтернатива успех

Ключевые возвраты

  • Из оформления → корзина: данные формы сохраняются в сессии/черновике.
  • Смена состава / адреса → сброс актуальности расчёта доставки (не принимать старую цену).
  • Неуспешная оплата → экран «заказ уже создан, оплатите» + кнопка повтора платежа.
  • Пустая корзина → CTA в каталог, оформление недоступно.
