Дмитрий, добрый день! Сверили макет с ТЗ, таблицей полей и вашими комментариями. Внёс все пункты в один согласованный вариант для компьютера и телефона. Ссылка (с обновлением кеша): https://whiteeze.github.io/rippo-cart-prototype/prototype/?v=20261127e В верхней панели: Корзина / Оформление + переключатель Desktop / Mobile 390. Кнопка «Mobile 390 · корзина» сразу открывает тот же экран корзины в ширине 390px — отдельного «другого» макета больше нет. ━━━━━━━━━━━━━━━━━━━━ ЧТО ИСПРАВЛЕНО ПО ЗАМЕЧАНИЯМ ━━━━━━━━━━━━━━━━━━━━ 1) Порядок блоков Сначала способ доставки, затем адрес / ПВЗ. Адрес больше не стоит выше доставки. 2) СДЭК ПВЗ — только нужные поля Для ПВЗ: населённый пункт + выбор пункта выдачи на карте. Улица, дом и квартира в этом сценарии не запрашиваются. 3) Населённый пункт один раз • ПВЗ: одно поле «Населённый пункт». • Курьер / Почта: поиск адреса; при выборе подсказки город, улица, дом и индекс заполняются автоматически — это подписано в форме и работает в прототипе. Отдельного дублирующего поля города нет. 4) Карта ПВЗ СДЭК В блоке ПВЗ показана схема размещения (карта + список). По кнопке «Открыть карту ПВЗ» открывается окно: • Desktop: карта слева (~60%), список справа. • Mobile 390: карта сверху (~55%), список снизу. Выбор — клик по метке или строке списка; выбранный адрес ПВЗ отображается в форме с кнопкой «Заменить на карте». 5) Наложенный платёж СДЭК — полный разбор сумм Отдельно показаны: товар, доставка, комиссия 3%, общая сумма, «Оплатить сейчас» (доставка), «Оплатить при получении» (товар + комиссия). Доставка — заранее; товар и комиссия — при получении. При полной онлайн-предоплате комиссия 3% не добавляется. 6) Условия оплаты — без сокращения Сохранена понятная формулировка: «Доставка оплачивается при оформлении заказа. Товар и комиссия СДЭК 3% — при получении.» Она продублирована в блоке оплаты и в итоге заказа при COD. 7) Мобильная корзина Убраны большие пустые промежутки между товарами, сетка компактнее. Горизонтальной прокрутки нет — контент умещается в 390px без уменьшения удобства кнопок −/+. ━━━━━━━━━━━━━━━━━━━━ ОКОНЧАТЕЛЬНЫЙ ФОРМАТ КОРЗИНЫ (один вариант) ━━━━━━━━━━━━━━━━━━━━ Предлагаем к реализации: • Desktop: — боковая мини-корзина (drawer справа) по клику на иконку в шапке — быстрый просмотр и переход к оформлению; — отдельная страница «Корзина» — полный состав, итог, CTA «Оформить заказ». • Телефон (Mobile 390): — только страница «Корзина» (тот же экран, адаптив); — выезжающий drawer на телефоне не используем: он перекрывал контент и дублировал сценарий. Отдельный «третий» мобильный макет из прототипа убран, чтобы не было расхождений. Зачем так: мини-корзина на десктопе экономит клик при добавлении товара; на телефоне надёжнее полноценная страница без боковой панели — проще править количество и сразу видеть итог. Прошу подтвердить эту структуру. После подтверждения соберём финальный комплект материалов (документы 01–07 + прототип) для передачи в разработку. С уважением
